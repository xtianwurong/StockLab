分位口径　分位 = 当前估值在该标的自身历史有效样本中低于当前值的占比（0~100%）， 越低越便宜；亏损期（PE/PB ≤ 0）样本剔除，故样本数会少于交易日数。 七档评级　0~10 极度低估 / 10~20 低估 / 20~40 正常偏低 / 40~60 正常 / 60~80 正常偏高 / 80~90 高估 / 90~100 极度高估。 名次　全市场名次由横截面分位升序位次现算，与全市场页同源。
数据　本地 DuckDB 仓库（数据截止 -）， 源自 AkShare / BaoStock / 腾讯 / 新浪 / 通达信 / 巨潮资讯等公开接口；指数与行业估值为成分股聚合口径。
免责　StockLab 为本地研究工具，结论均由公开数据按上述口径算出，仅供学习参考，不构成投资建议。
